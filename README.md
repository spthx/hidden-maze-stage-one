# HIDDEN MAZE - 1 Stage Prototype

見えない6×6の迷宮を、壁と出口までの距離反応を手掛かりに探索するブラウザゲームの試作版です。

## ルール

- 上下左右へ1マスずつ移動します。
- 通路なら移動し、通ったマスが見えるようになります。
- 壁なら移動できませんが、その壁が盤面に表示されます。
- 移動と壁への衝突は、どちらも1手を消費します。
- 表示される「出口反応」は、現在地から出口までのマンハッタン距離です。
- 20手以内に出口へ到達すればクリアです。
- クリアまたは失敗時に、迷宮全体、最短経路、実際に通った経路を表示します。

## 操作

- スマートフォン：画面下の方向ボタン
- PC：矢印キーまたはWASD

## ローカルで遊ぶ

JavaScriptのモジュールを使用しているため、簡単なローカルサーバーから開いてください。

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## テスト

外部パッケージは不要です。

```powershell
npm test
```

## GitHub Pages

1. このフォルダをGitHubリポジトリへ登録します。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選択します。
4. 公開ブランチとルートフォルダ `/ (root)` を指定します。

相対パスだけを使用しているため、そのままGitHub Pagesで動作します。
