# HIDDEN MAZE - Three Dungeons

暗闇の自動生成迷宮で武器と探索道具を見つけ、先制攻撃でボスを倒すスマートフォン向けブラウザゲームです。

## 3つのステージ

- ステージ1：5×5、剣、宝箱1個
- ステージ2：6×6、ヤリ、宝箱2個、仲間と罠
- ステージ3：8×8、弓、宝箱3個、宝箱モンスター

各ステージは開始時に自動生成されます。「別の迷宮を生成」で同じ難易度の新しい配置に変更できます。

## 武器

- 剣：隣接する敵へ攻撃、3回
- ヤリ：直線1～2マスへ攻撃、2回
- 弓：直線2～4マスへ攻撃、2回。隣接する敵には使えません
- 素手：敵のマスへ踏み込むと倒せますが、通常敵からHP1、ボスからHP2の反撃を受けます

壁や別の敵を越えて攻撃することはできません。武器で先制攻撃すれば反撃を受けません。

## 探索

- 松明：壁に遮られない周囲3×3を地図へ記録
- 光魔法：壁に遮られない周囲5×5を地図へ記録
- 仲間：隣接する罠と宝箱モンスターを事前に識別
- 宝箱：開けるか置いていくかを選択

ボス、通常モンスター、宝箱モンスターを合わせた脅威数は、1ステージ最大3体です。各ステージの宝箱には必ず武器が1個入っています。

## 操作

- スマートフォン：画面の方向、攻撃、松明、光魔法ボタン
- PC：矢印キーまたはWASD
- `F`：攻撃対象選択
- `T`：松明
- `L`：光魔法

## テスト

外部パッケージは不要です。

```powershell
npm test
```
