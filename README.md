# HIDDEN MAZE — Rival Expedition

スマートフォンのブラウザで遊ぶ、1人用の自動生成・戦術迷宮ゲームです。

## 今回の試作ルール

- 5×5、6×6、7×7、8×8の4ステージ
- 他の冒険者は最寄りの未開封宝箱へ進み、先に到着すると中身を奪う
- モンスターはプレイヤーと冒険者の近い方を追跡する
- 冒険者を囮にして逃げることも、攻撃して奪われた宝を回収することもできる
- 遠くの人物はすべて「?」で表示され、隣接するまで正体が分からない
- 剣、ヤリ、弓は使用回数と射程が異なる
- 6×6以降のボスは銀の剣で隣接攻撃しないと倒せない
- ステージ開始ダイスは奇数が不利、偶数が有利
- 8×8には2×2の隔離された隠し部屋があり、転移床から入る
- 隠し部屋は宝物庫またはモンスターハウス

## 操作

画面の方向ボタンで移動します。ATTACKを押した後、射程内の「気配」を選ぶと攻撃します。松明は周囲3×3、光魔法は周囲5×5を照らしますが、壁の向こう側は見えません。
